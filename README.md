# DEFT: Differentiable Automatic Test Pattern Generation — Supplementary Material

This repository hosts the supplementary material (appendices) for the paper

> Wei Li, Yang Zou, Yixin Liang, José Moura, and Shawn Blanton,
> "DEFT: Differentiable Automatic Test Pattern Generation,"
> *IEEE International Test Conference (ITC)*, 2026.

**[DEFT_ITC26_supplementary.pdf](DEFT_ITC26_supplementary.pdf)** contains:

- **Appendix A** – Proofs (Theorem IV.1: formulation equivalence; logistic reparameterization)
- **Appendix B** – DEFT hyperparameters
- **Appendix C** – Commercial ATPG scripts (S1–S4) used in the experimental flow

Theorem, equation, and figure numbers not defined in the supplement refer to the main paper.
